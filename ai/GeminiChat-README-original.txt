GEMINI CHAT

Open GeminiChat.exe and start typing. Your supplied key is already built in;
there is no key entry screen. Enter sends; Shift+Enter adds a new line.
Click the purple arrow to send, or New chat to reset the conversation.
Dark purple design with a rounded composer inspired by your reference.

The default is gemini-3.8-flash. The key and model passed a live API test
in the previous revision. This revision passed compilation, response parsing,
window initialization, and Enter/Shift+Enter routing checks.

Requires internet and Windows .NET Framework 4.5 or later.
Messages go directly to Google's Gemini API over HTTPS.
Conversation history is kept in memory only. Google controls API quota/billing.
Keep this personal executable and source private: they contain your API key.

Source: GeminiChat.cs. Rebuild with build.ps1 in Windows PowerShell.
