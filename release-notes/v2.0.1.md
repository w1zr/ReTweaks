# RETWEAKS v2.0.1

A fix for the **AI assistant**. Everything else is the same as [v2.0](https://github.com/w1zr/ReTweaks/releases/tag/v2.0); see its notes for the full list of features.

Website: https://retweaks.plumheron1.chatgpt.site/ · Discord: https://discord.gg/fS5NwW9TPF

## Fixed
- **AI assistant showed "Google HTTP 401: API key not valid".** The shared Gemini key in v2.0 was disabled by Google shortly after release. v2.0.1 fixes it in two ways:
  - **Use your own key:** the AI assistant page has a new **Your Gemini key** box.
    1. Click **Get a free key**; it opens Google AI Studio.
    2. Copy the key and paste it into the box.
    3. Click **Save key**, and the AI reloads with it straight away.
  - **Remove my key** goes back to the built-in key.
  - Your key is stored only on this PC, encrypted for your Windows account, and is sent only to Google. Google's terms require you to be 18 or older.
  - Price checks, driver help and the AI service check use the same key.
  - **Built-in key:** a shared key is now added when the release is built and is no longer stored in the public source code.
- If Google rejects a key, the AI page now says so and points you to the key box.

## Updating
Use **Update now** in the app, or download `RETWEAKS.exe` below. Your settings are kept.

The .exe isn't code-signed, so Windows SmartScreen or antivirus may warn. License: GPL-3.0-only.
