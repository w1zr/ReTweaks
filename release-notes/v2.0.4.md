# ReTweaks 2.0.4

This release brings together the updates and fixes since 2.0.3.

## Dashboard and navigation
- Combined Overview and Quick Start into one Dashboard with live hardware readings, quick actions and preset recommendations.
- Consolidated tweak collections into Tweaks & presets, and the benchmark, FPS and comparison tools into Benchmark & FPS.
- Grouped related tools with relevant section names while retaining their functions. Restored direct access to Drivers, File Transfers, Windows backgrounds and App Starter.
- Fixed sidebar scrolling into empty space, removed duplicate controls, and added first-run guidance about switching categories inside pages.

## Hardware detection and drivers
- Improved physical GPU detection to avoid duplicate, virtual and remote adapters while retaining real multi-GPU systems.
- Scan currently connected components across graphics, chipset/system devices, network/Wi-Fi, Bluetooth, audio, storage/controllers, USB, displays, input devices, cameras, firmware and other supported categories.
- Hide NVIDIA, AMD or Intel installer panels when matching hardware is absent. Driver categories reflect detected components rather than a fixed list.
- Download supported official vendor installers inside ReTweaks, show progress and cancellation, verify the publisher, and launch the normal setup flow. Windows Update offers applicable driver updates for other detected devices.
- Retain model-specific official support links where a direct installer cannot be reliably identified.

## Browser, embeds and search
- Fixed missing EmbeddedBrowser.exe packaging and frozen-build helper lookup; validate browser components before packaging.
- Added full-page Windhawk and Windows Activation pages using the existing isolated embedded-site system.
- Rounded browser menus and fixed unreadable text and selection marks in the search-engine submenu.
- Search individual tweaks by name, description or category. Exact names take priority; choosing a result opens its filtered list without applying it.
- Added local filtering in All tweaks while preserving selections.
- Fixed search results behind embedded pages, keyboard focus, stale results after navigation and Ctrl+K forwarding from browser/site windows.
- Added packaged startup and native-browser self-checks.

## AI and Discord
- Added contextual AI help for hardware, parts, drivers and tools. Explain selected tweaks appears only where relevant; AI advice does not automatically change settings.
- Updated Discord Rich Presence with the ReTweaks chip logo, Optimizing with RETWEAKS, Windows PC tweaks and elapsed time.
- Discord's website button reads **Get Retweaks** and opens https://w1zr.github.io/ReTweaks/.

## Backgrounds and appearance
- Added Windows wallpaper previews, local images, gradient presets, favorites, fit controls, monitor selection and backup/restore.
- Added Transparent TB (taskbar), with a description and a Download action that installs official TranslucentTB.
- Added optional Lively Wallpaper integration for animated wallpapers, with playback controls.
- Expanded app animation options and simplified theme/animation controls to remove repeated settings; hidden animations pause rendering.
- Renamed the sidebar entry Windows backgrounds and fixed its icon.
- Matched the About Website button to the dark interface.

## File Transfers
- Send multiple files and folders together, including mixed selections, using encrypted share codes.
- Temporary uploads support up to **1 GB including archive/encryption overhead**, with 1, 12, 24 or 72-hour expiry choices through Litterbox.
- Recipients can download after the sender goes offline. Downloads remain archives and are not automatically extracted or executed.
- Added transfer progress, cancellation and selection limits. ReTweaks imposes no daily transfer-count reset; provider availability and policies still apply.

## Gaming and overlay
- Added Fortnite-specific stretched-resolution configuration with backup/restore, without changing the entire Windows desktop resolution. Results depend on the game's display mode and driver support.
- Expanded optional FPS overlay readings: 1% and 0.1% lows, averages/minimums/maximums, frame time, CPU/GPU use, RAM/VRAM, temperatures, clocks and power where available.
- Added layout and refresh controls. Unsupported readings remain unavailable; no game-process injection is used.

## Installation and reliability
- Automatically install missing WebView2, PawnIO and PresentMon when their features need them; Lively setup is triggered by animated-wallpaper actions. Existing installs are reused and automatic setup can be disabled in Settings.
- Added prerequisite setup/build scripts, verified downloads, background installation status and restart/error reporting.
- Fixed Qt DLL conflicts affecting startup and included required helper assets, third-party tools and licenses in the single-file build.
- Preserve existing settings, presets, profiles and navigation aliases.

## Validation and limits
- 422 automated tests passed, alongside navigation, filtered-search, browser lifecycle and remembered-section UI checks.
- The release EXE is checked for packaged startup and native browser/menu/shortcut behavior before publishing.
- Dependency installer paths were tested with mocked installers; this validation did not install third-party programs or apply drivers/tweaks on the test PC. Hardware-specific installations and Fortnite behavior depend on the target system.
- Downloads include RETWEAKS.exe, a ZIP copy and a SHA-256 checksum. AI credentials stay out of public source; the built helper supplies the configured shared AI connection.
