# RETWEAKS v1.6

**RYTWEAKS is now RETWEAKS.** Same app, same chip logo, new name, with the **ReTweaks** wordmark.

### Your settings come with you
The first time v1.6 starts, it moves everything over from the old name:
- Settings, themes, tweak undo data, game preset backups, program rules, bookmarks and history (`%APPDATA%\RYTWEAKS` → `%APPDATA%\RETWEAKS`)
- Browser cookies and logins (`%LOCALAPPDATA%\RYTWEAKS` → `%LOCALAPPDATA%\RETWEAKS`)
- Your saved AI Assistant key
- Start with Windows (it now opens RETWEAKS.exe)

The old folders are kept as a backup; you can delete them once everything works. If the old RYTWEAKS is still running in the tray, RETWEAKS offers to close it first. Theme codes and preset files shared before the rename still import.

### Download
The program is now **RETWEAKS.exe**. The repository is **github.com/w1zr/retweaks** (the old address redirects).

RYTWEAKS v1.5.1 can't update itself to v1.6 because the file name changed, so download RETWEAKS.exe from this page once. Everything from v1.5.1 is unchanged.
