# ReTweaks 2.0.6

**Download:** `RETWEAKS.exe` (or `RETWEAKS.zip`) below. Already have ReTweaks? Click **Update now** in the app. Your settings are kept.

## What's new

- **Banner colour.** Settings → Appearance → **Banner color**:
  - **Original:** the purple galaxy, as before. This stays the default.
  - **Black & white:** a grey-and-white galaxy that suits the Super Black theme.
  - **Theme accent:** the banner follows your theme's accent colour.
  - **Custom (HEX):** any colour you type, for example `#10b981`.

  It applies to every banner style (galaxy, CPU cores, load wave and circuit) and changes right away.
- **Updates always come from GitHub releases.** Update now and automatic updates download `RETWEAKS.exe` from the latest GitHub release and check its SHA-256 before installing.
  - In `RETWEAKS.exe`, the update replaces the program and keeps the previous version as `RETWEAKS.old.exe`, as before.
  - When ReTweaks runs from source code, it no longer says "use git pull". The released `RETWEAKS.exe` is saved in `%LOCALAPPDATA%\RETWEAKS\app` and starts instead. Your own folders and files are never changed.
- Translations for the new texts in Español, Français, Deutsch and Português (Brasil).

Full feature list: see the [2.0.5 release](https://github.com/w1zr/ReTweaks/releases/tag/v2.0.5).
