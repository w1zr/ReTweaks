# ReTweaks 2.1

**A free Windows PC optimizer with real hardware readings, reversible tweaks and honest results.** No fake numbers and no promised FPS gains: every control does a real Windows action and shows what actually happened.

Website: https://w1zr.github.io/ReTweaks/ · Discord: https://discord.gg/fS5NwW9TPF · Source: https://github.com/w1zr/ReTweaks

**Download:** `RETWEAKS.exe` (or `RETWEAKS.zip`) below. It's a single file and needs no installer. It asks for administrator rights because many tweaks change system settings. Already have ReTweaks? Click **Update now** in the app. Your settings, themes, tweak history and backups are kept.

## Everything in ReTweaks 2.1

### Monitor

**Dashboard**
- Live CPU load per thread and the real current CPU clock (not just the base clock).
- GPU load for every GPU brand, from the same Windows counters Task Manager uses.
- VRAM, memory, disk read/write and network up/down, plus temperatures when a sensor is available.
- An animated banner: CPU cores, load wave, circuit or galaxy, or off. Its colour can be the original purple, black & white, your theme's accent or any HEX colour.
- Quick actions: **Tune your PC**, **Find drivers** and **Set up apps**.
- Windows Game Mode status and game detection, with a preset recommendation for your hardware.
- AI help buttons to explain the readings or investigate slow performance.
- Anything Windows can't report shows **Unavailable**, never a made-up number.

**Hardware & cooling**
- **Hardware and PC specs:**
  - the exact GPU name and full 64-bit VRAM through DirectX, with every GPU listed
  - CPU, motherboard and BIOS, each RAM stick and disk health
  - monitors, audio devices and network adapters
  - a hardware report you can export
- **Temperatures:** live CPU, GPU and drive temperatures. One °C/°F setting is used everywhere. CPU and motherboard sensors need the free PawnIO driver, which ReTweaks sets up when this page needs it.
- **Fans:**
  - live speeds, and manual speed from 30 % to 100 % (pumps are never touched)
  - fan curves that follow the CPU, the GPU or whichever is hotter: Silent, Balanced, Performance and Full speed presets, or your own curve
  - **Safety:** fans return to automatic BIOS control when you quit, if ReTweaks crashes, if a temperature can't be read for 8 seconds, or at 85 °C.
- **RGB lighting:** fans and RAM through the built-in OpenRGB.
  - Effects: solid colours, Rainbow, Breathing and Color cycle.
  - Brightness, per-device on/off and saved profiles.
  - Changing the RAM colour sets every stick.
- **Display:**
  - checks each monitor runs at its highest refresh rate
  - whole-screen stretched resolution with a 15-second "Keep?" trial
  - shows graphics driver information

**Health & recovery**
- **Health check:** one scan of startup apps, temporary files, power plan, disk health, pending updates and more, with **Fix** buttons that use reversible tweaks.
- **Backups & fixes:**
  - create a restore point or open System Restore
  - export and import your preset selections
  - check Windows system files
  - open Windows troubleshooting

**Benchmark & FPS**
- **Graphics benchmark** and **Bottleneck** tester.
- **FPS test:** average FPS plus 1% and 0.1% lows measured with Intel PresentMon (set up automatically when needed), with test lengths from 10 seconds to 30 minutes.
- **FPS overlay:** a click-through window over borderless or windowed-fullscreen games. It never injects into the game, so it's safe with anti-cheat.
  - Switch each reading on or off: FPS, 1% and 0.1% lows, average/min/max, frame time, CPU and GPU use, RAM and VRAM, temperatures, clocks and GPU power.
  - Set the layout, refresh rate, screen-edge spacing and FPS precision.
- **Comparisons:** before/after snapshots, FPS run comparisons and sensor logging to CSV.

### Optimize

**Tweaks & presets**
- **Presets (12 one-click options):**
  - Max FPS, Esports, Balanced, Streamer, Low-end PC, Laptop
  - Privacy, Clean, All safe tweaks
  - Chris Titus Tech Standard, Minimal and All safe

  Every preset shows what will change first.
- **Manual tweaks:**
  - **117 tweaks** in 13 categories: Performance, Gaming, Network, Privacy, Interface, Services & Debloat, Maintenance and the Chris Titus Tech sets.
  - **53 tweaks with exact undo:** ReTweaks saves each original value first, so Undo puts back exactly what you had. Undo everything reverts them all, and you can make a restore point first.
  - Each tweak explains what it does and its downside, says if it needs administrator rights, and shows its current state.
  - Nothing applies until you press Apply.
- **Search tweaks** by name, description or category, from the page or from the top search bar (Ctrl+K).
- **CTT library**, **Windows tweaks** and **Customize** (Windows appearance, privacy and security options with Apply/Undo selected).

**Gaming tools**
- **Game profiles** for 11 games: Fortnite, Valorant, Counter-Strike 2, Apex Legends, Call of Duty: Warzone, Minecraft (Java), GTA V, Roblox, League of Legends, Rocket League and Overwatch 2.
- **Config files:** edit the game's own settings file for Fortnite, Minecraft Java and Bedrock, Apex Legends and Rocket League, or any file you choose.
  - Low, High, Ultra and Ultra Performance presets, plus your own, with import and export.
  - Backs up first, only changes settings already in the file, and refuses while the game runs.
- **Fortnite-only stretched resolution:** sets Fortnite's own resolution and Fullscreen mode, with a backup and a resolution-only restore. Windows and other apps keep their normal desktop resolution.
  - Finds Fortnite's settings file automatically, in every Windows user profile, and shows where it is.
  - Makes the file read-only after saving so Fortnite can't reset it (on by default; Restore unlocks it).
  - Checks first whether your graphics card offers that size, and explains how to add it if not.
- **Program rules:** per-program GPU preference, fullscreen optimizations and CPU priority, plus auto game mode, which lowers the priority of only the background apps you pick while you play.
- **Crosshair:**
  - a click-through crosshair overlay with 33 built-in crosshairs
  - an editor with 12 styles, including your own image
  - share codes (`RTX1-…`) and an online gallery
  - F9 to show or hide it
- **Auto clicker:**
  - left, right or middle button; single or double click
  - CPS or interval, random range and start delay
  - hotkeys and an emergency stop
- **Mouse tests:** polling rate, clicks-per-second and reaction time.

**Network**
- **DNS:** pick a preset, enter your own IPv4/IPv6 servers or set Automatic, per network adapter, with one-click restore.
- **DNS speed test:** real, uncached lookups showing average, best, worst and failures.
- **Ping test:** to 1.1.1.1 or 1.0.0.1.
- ReTweaks never changes DNS on its own.

**Drivers**
- Scans currently connected hardware: graphics, network/Wi-Fi, Bluetooth, audio, storage, chipset, USB, displays, input devices, cameras and firmware. A category filter narrows the list.
- **Install driver:**
  - for detected NVIDIA, AMD and Intel hardware, it downloads the official installer inside ReTweaks
  - it shows progress, checks the publisher's digital signature, then runs the maker's setup
- **Windows Update:** offers driver updates for other devices.
- Exact-model support links for BIOS and firmware.

## Good to know

- Overlays (FPS and crosshair) show over borderless or windowed-fullscreen games, not exclusive fullscreen.
- Sensors, fan control and RAM lighting depend on your motherboard. Some boards don't allow fan control, and ReTweaks says so instead of pretending.
- The .exe isn't code-signed, so Windows SmartScreen or antivirus may warn. On the blue "Windows protected your PC" screen, choose **More info → Run anyway**. Since 2.0.8 it isn't UPX-compressed and its launcher is built from source, which avoids many false warnings. Some antivirus tools also flag the built-in hardware-monitoring tools (LibreHardwareMonitor and OpenRGB, included with their licenses).
