# RETWEAKS v2.0

**The biggest RETWEAKS update so far.** v2.0 is a full rebuild: a new, faster interface, 46 pages, 117 tweaks plus 53 with exact undo, temperatures, fan control, RGB lighting, a crosshair overlay, a built-in browser, five languages and much more. Everything from v1.6 is still here, and your settings carry over.

Website: https://retweaks.plumheron1.chatgpt.site/ · Discord: https://discord.gg/fS5NwW9TPF · Source: https://github.com/w1zr/ReTweaks

**Download:** `RETWEAKS.exe` (or `RETWEAKS.zip` if you prefer a .zip). It's a single file and needs no installer. It asks for administrator rights because many tweaks change system settings. If you have v1.6, the in-app updater offers v2.0 automatically.

## Getting started

### Welcome tour
- Shown once to everyone opening v2.0 or later. Replay it any time from **Settings → Show the welcome tour again**.
- It covers:
  - how RETWEAKS works (nothing changes until you press Apply)
  - °C or °F
  - your language
  - automatic updates
  - closing to the tray
  - an optional desktop shortcut
- Your choices apply only when you press **Next**.

### Languages
- English, Español, Français, Deutsch and Português (Brasil). Every page is covered.
- Switch from the language card at the top of Settings. No restart is needed.

### Global search (Ctrl+K)
- The search bar at the top of the window finds pages, settings and individual tweaks.
- Click a result, or use the arrow keys and Enter, to jump straight to it.

## Monitor

### Dashboard (home screen)
- Live CPU load per thread and live CPU clock speed (the real current clock, not the base clock).
- GPU load for every GPU brand, from the same Windows counters Task Manager uses.
- VRAM, memory, disk read/write and network up/down speeds.
- Temperatures when a sensor is available.
- Animated banner: cores, wave, circuit or galaxy, or off.
- Updates every second by default, adjustable in Settings. Anything Windows can't report shows **Unavailable**, never a made-up number.

### Hardware and PC specs
- The exact GPU name and full 64-bit VRAM through DirectX, so cards over 4 GB are no longer shown as 4 GB.
- Every GPU in the PC is listed.
- CPU, motherboard and BIOS, each RAM stick, disk health, monitors, audio devices and network adapters.
- Export a hardware report.

### Temperatures (new)
- Live CPU, GPU and drive temperatures, with CPU package, cores, motherboard and GPU hotspot where available.
- One °C/°F setting is used everywhere. Change it on the Temperatures page or in Settings → Behavior.
- Uses the bundled LibreHardwareMonitor, so you no longer have to run it separately.
- CPU and motherboard sensors need the free **PawnIO** driver, which Windows requires to read them. The page has a button to its official download page. RETWEAKS never installs drivers itself.

### Health Check
- One scan of startup apps, temporary file size, power plan, disk health, pending updates and more.
- Each finding has a **Fix** button that uses the same reversible tweaks.

### FPS overlay and FPS test
- **FPS overlay:** a click-through window on top of borderless or windowed-fullscreen games. It never injects into the game, so it's safe with anti-cheat.
  - It shows current FPS and 1% lows.
  - The FPS averaging span is adjustable: 0.5, 1 or 2 seconds.
  - The 1% low window is adjustable: 5, 10, 30 or 60 seconds.
  - The page explains what each number means.
- **FPS test:** measures average FPS plus 1% and 0.1% lows with Intel PresentMon (free, downloaded separately).
  - Lengths: 10 s, 30 s, 60 s, 120 s, 5 minutes, or a custom length from 5 to 1800 s.
  - Runs can be compared before and after in Snapshots.

### Benchmark
- A browser render benchmark, plus a Bottleneck tester in Tools.

### Display
- Checks whether each monitor runs at its maximum refresh rate, and applies it if not.
- **Stretched resolution** for every game, per monitor.
  - On NVIDIA it can add a missing custom resolution.
  - Every change is a 15-second trial: if you don't press Keep, it reverts.
- Shows the GPU driver version and its age.

## Optimize

### Quick start and Presets
- 12 one-click presets:
  - Max FPS, Esports, Balanced, Streamer, Low-end PC, Laptop
  - Privacy, Clean, All safe tweaks
  - Chris Titus Tech: Standard, Minimal and All safe
- Every preset shows what will change before it applies.

### Individual tweaks
- **All tweaks tab (117 tweaks)** in 13 categories:
  - Performance, Gaming, Network, Privacy, Interface, Services & Debloat, Maintenance
  - CTT Essential, CTT Advanced (caution), CTT Customize, CTT Features, CTT Fixes, CTT Updates
- **Exact undo tab (53 tweaks)** in Gaming, Privacy, Interface, Services and Maintenance. Some change the same Windows setting as a tweak in the first tab:
  - RETWEAKS saves each setting's original value before changing it.
  - **Undo** puts back exactly what you had, not just a Windows default.
  - **Undo everything** reverts all of them at once, and you can create a restore point first.
- Each tweak explains what it does and its downside, says if it needs administrator rights, and shows its current state. Nothing is applied without you pressing Apply.
- The **CTT library** and **Windows tweaks** pages give quick access to the same sets.

### Customize
- Windows appearance, privacy and security options.
- Use **Apply selected** and **Undo selected**.

### Game profiles (11 games)
- Fortnite, Valorant, Counter-Strike 2, Apex Legends, Call of Duty: Warzone, Minecraft (Java), GTA V, Roblox, League of Legends, Rocket League and Overwatch 2.

### Game config files
- Edits the game's own settings file for Fortnite, Minecraft Java, Minecraft Bedrock, Apex Legends and Rocket League, or any file you choose.
- Low, High, Ultra and Ultra Performance presets plus your own custom presets, with import and export.
- Backs up first, changes only settings that already exist in your file, and refuses while the game is running.
- Fortnite's settings file can be locked so the game doesn't overwrite it.

### Program rules
- Per-program GPU preference, fullscreen optimizations and CPU priority.
- **Auto game mode:** while a game runs, RETWEAKS lowers the priority of only the background apps you pick, then restores them.

### Startup apps
- Everything that starts with Windows: Run keys, Startup folders and Scheduled Tasks.
- Shows name, path, publisher and scope.
- Disable and re-enable any entry. The original is kept so it can be restored.

### Network
- **DNS:**
  - Choose a preset, enter your own IPv4/IPv6 servers, or set Automatic (from router).
  - Works per network adapter, with one-click restore.
- **DNS speed test:** real, uncached lookups against each server, showing average, best, worst and failures.
- **Ping test:** to 1.1.1.1 or 1.0.0.1.
- Results are for your PC and network at that moment. RETWEAKS never changes DNS on its own.

### Drivers (new: download and install)
- Finds the latest driver for your hardware:
  - **NVIDIA:** from NVIDIA's own driver lookup.
  - **AMD:** AMD's official auto-detect installer.
  - **Intel:** Intel Driver & Support Assistant.
  - **Windows Update:** driver updates.
- Asks before downloading and again before running anything, and checks the file's digital signature first.
- The driver list and links are still there.

## Tools

### Browser (new)
- RETWEAKS' own browser, built on Microsoft Edge's engine (WebView2). It runs as its own program, so a browser problem can't close RETWEAKS.
- Tabs, private tabs, reopening a closed tab, back/forward/reload, zoom and print.
- Pop-ups open as tabs, and full-screen video works.
- New-tab shortcut tiles, bookmarks and history (searchable, clearable; private tabs are never saved), and the Edge downloads list.
- Search engines: Google, DuckDuckGo, Brave Search, Bing, Startpage or your own.
- A settings page for site permissions, autofill and passwords, and clearing cookies and site data.
- Your bookmarks from earlier versions carry over.

### Fan control (new)
- Live fan speeds (RPM).
- Manual speed for one fan, all system fans or all GPU fans, from 30 % to 100 %. Pumps are never touched.
- **Fan curves:**
  - Follow the CPU, the GPU or whichever is hotter.
  - Silent, Balanced, Performance and Full speed presets, or your own curve with 4–6 draggable points.
  - Smooth ramping so fans don't jump around.
- **Safety:** fans go back to automatic BIOS control when you quit, if RETWEAKS crashes, if a temperature can't be read for 8 seconds, if monitoring stops, or when the CPU or GPU reaches 85 °C.
- Nothing changes your fans at startup unless you turn on "apply fan curves at start".
- Most fan control needs the free PawnIO driver.

### RGB lighting (new)
- Fans, RAM or both, through the bundled OpenRGB.
- Effects: solid colours and presets, Rainbow (synced, adjustable speed), Breathing and Color cycle.
  - Breathing and Color cycle appear only when every controller supports them.
- Brightness, per-device on/off, and saved lighting profiles.
- Changing RAM colour sets every RAM stick, not just one.
- Advanced: device, zone and mode setup, plus LED count.
- Nothing changes your lighting at startup unless you turn on "apply a profile at start".
- RAM lighting usually needs the PawnIO driver.

### Crosshair (new)
- A click-through crosshair on top of borderless or windowed games, like Crosshair X. It never touches the game.
- **33 built-in crosshairs**, including a pack of streamer-style crosshairs.
- **Editor:**
  - 12 styles, including your own PNG image.
  - Colour, opacity, length, thickness, gap, outline, centre dot and rotation.
- Saved "My crosshairs", **share codes** (`RTX1-…`), `.rtxhair` files and an online gallery.
- **F9** shows or hides it, or choose your own hotkey. You can also pick the monitor and offset, and show it at startup.

### Storage and Cleanup
- **Storage Explorer:** browse with breadcrumbs, search, sort, show hidden files, copy path and open files.
- Folder sizes are calculated in the background, with a disk usage breakdown.
- **Cleanup:** temporary files (your Temp folder and Windows\Temp), always with a preview first. Nothing is deleted automatically.

### Audio mixer
- Master volume and mute, per-app volume and output device switching.
- The default microphone too, and a pop-out mini mixer.
- **Volume lock** keeps your speaker or mic volume at the level you choose.

### Auto clicker
- Left, right or middle button, single or double click.
- Set CPS or an interval, a random interval range, a start delay, a click count or run time, and a fixed position.
- Hotkeys plus an emergency stop that always works.
- Please follow each game's rules.

### AI assistant
- Ask about your PC and get advice. It uses Google's Gemini (see v2.0.1 for the key fix).
- What you type is sent to Google. Google's Gemini terms require users to be 18 or older.
- Advice only: it never changes settings by itself.

### More tools
- **Run:** quick launch for Task Manager, Resource Monitor, Event Viewer, Services, Disk Management and more.
- **Daily Tools:** image to text (Windows OCR), image converter and resizer, images to PDF, text toolbox, file checksum and colour picker. All local.
- **App Starter:** install 100 popular apps.
- **PC Value Checker** (beta).
- **3D PC Builder.**
- **Bottleneck** tester.
- **Snapshots:** before/after system snapshots, FPS run comparisons and sensor logging to CSV.
- **Fun tools:** mouse polling rate, CPS test and reaction test.
- **Tools** and **Advanced tools.**
- **Backups & fixes:** create a restore point or open System Restore, export and import your preset selections, check Windows system files (check only, no repair) and open Windows troubleshooting.
- **Tips**, **Help**, an **Activity** log and **Notifications**.

## Good to know

- **Built and tested on Linux with simulated Windows APIs. This is the first release tested on real hardware**, so please report anything that doesn't work on GitHub or Discord.
- Hardware sensors, fan control and RAM lighting depend on your motherboard and the PawnIO driver. Some boards don't allow fan control at all, and RETWEAKS says so instead of pretending.
- Overlays (FPS and crosshair) show over borderless or windowed-fullscreen games, not exclusive fullscreen.
- Known limits in this version:
  - The Light theme isn't available (a saved Light choice uses Graphite).
  - Galaxy has no full-window starfield.
  - The theme maker's text and status colours are saved but not applied.
  - Startup apps don't show program icons.
  - FPS overlay opacity also fades the text.
  - Browser tabs can't be dragged to reorder.
- The .exe isn't code-signed, so Windows SmartScreen or antivirus may warn. Some antivirus tools also flag the bundled hardware-monitoring tools (LibreHardwareMonitor, OpenRGB), which are included with their licenses and source links.
- The AI assistant uses a shared Google Gemini key built into the app. Google disabled that key shortly after release; v2.0.1 adds a box to use your own free key.
