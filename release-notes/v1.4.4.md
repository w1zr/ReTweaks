## RETWEAKS v1.4.4

### FPS overlay without PresentMon
The in-game overlay now has its own built-in frame counter, so you don't need to download PresentMon for it. RETWEAKS reads the frame events Windows itself records every time a game shows a frame (the same data PresentMon uses) and measures the time between frames. Nothing is injected into the game. DirectX games use DirectX's frame events; OpenGL and some Vulkan games use the Windows graphics kernel's events, and the overlay page tells you which one it's using. You can still pick **PresentMon** under **Frame data** if you prefer. The FPS test still uses PresentMon.
- If the overlay can't start, a pop-up now tells you exactly why.

### Search and select tweaks
- The **Tweaks** page has a **search box**: try "sticky keys", "mouse" or "notifications".
- Every tweak has a checkbox. Pick a preset and press **Select its tweaks**: it ticks every tweak in that preset and sets each to On or Off. Untick any you don't want, tick more (or **Select all shown** after a search), use **Clear selection** to start over, then press **Apply selected**. RETWEAKS first reads your current settings and shows only what will actually change.

### More presets
**Low-end PC**, **High quality**, **Ultra quality** and **Streamer** join Esports, Max FPS, Balanced, Privacy, Max Performance and Windows Default. Each card shows exactly which tweaks it turns on and off. No preset promises an FPS gain; check with the FPS test.

### 9 more tweaks (53 in total)
Power throttling, CPU reserved for background tasks (MMCSS), notification banners, the Narrator shortcut (Ctrl+Win+Enter), Microsoft Edge running in the background, shortest key-repeat delay, opening Game Bar with the controller's Xbox button, Recall snapshots (Copilot+ PCs) and seconds in the taskbar clock. Each explains its trade-off and has its own **Undo**.

Everything from v1.4.3 is unchanged. Use the **Update now** bar at the top of RETWEAKS to update. Your settings are kept.
