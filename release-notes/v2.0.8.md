# ReTweaks 2.0.8

**Download:** `RETWEAKS.exe` (or `RETWEAKS.zip`) below. Already have ReTweaks? Click **Update now** in the app. Your settings are kept.

## What's new

- **More reliable first launch.**
  - If something goes wrong while ReTweaks opens, it restarts itself once instead of stopping with an error. If it still can't start, it says where the details were saved (`%APPDATA%\RETWEAKS\crash.log`) so the problem can be reported.
  - Optional first-run steps (the welcome tour, carrying over old data, translations, automatic updates) can no longer stop the app from opening. A failure is written to the log and skipped.
  - The first launch on a PC can take a while because Windows and antivirus check the new file. Double-clicking again during that time no longer shows a "not responding" message; the copy that's already starting opens.
- **Fewer false antivirus warnings.**
  - The program is no longer compressed with UPX, which antivirus software often flags.
  - Its launcher is now built from source for ReTweaks instead of using the shared ready-made one.
  - The file now carries its details (name, version, description) in Properties → Details.

  ReTweaks still isn't code-signed, so Windows may still show the blue "Windows protected your PC" screen for a new download. Choose **More info → Run anyway**.

Full feature list: see the [2.0.5 release](https://github.com/w1zr/ReTweaks/releases/tag/v2.0.5).
