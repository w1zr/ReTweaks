## RETWEAKS v1.2

### Accurate hardware for every PC
- **Live GPU load for every GPU** (NVIDIA, AMD, Intel, laptops with two GPUs), from the same Windows counters Task Manager uses.
- **Correct VRAM on every card**, read from DirectX (fixes the old 4 GB limit).
- **Live CPU clock speed** (it used to show only the base clock).
- **Real RAM details:** type (DDR4/DDR5), speed and slots used.
- **Real disk health** as reported by Windows, and real monitor names.
- **Temperatures and fans** when [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) is running with its web server on (Settings → Temperatures & fans shows how).
- Anything Windows doesn't report now shows **"Unavailable"** instead of a guessed number.
- **Export hardware report** (JSON, text or CSV) with no serial numbers or personal info, to attach to GitHub issues.

### New look
- Clean dark dashboard with live 60-second graphs for CPU, RAM, each GPU, disk and network.
- Sidebar grouped into Monitor, Optimize and Tools. Themes now color the whole app.
- The window no longer freezes while Windows is being queried.

### Tweaks that really work
- Every tweak shows its **real current state** from Windows: Game Mode, power plan, HAGS and Xbox Game Bar recording.
- The Ultimate Performance power plan saves your old plan, so **Restore previous** can switch back.
- DNS: Cloudflare, Google, Quad9, **custom servers** (IPv4/IPv6), Automatic, and **Restore previous**.
- Temp cleanup shows what it will delete before deleting.
- Profiles apply real tweaks and show the result of each step.

### Changed or removed
- The per-game profiles from v1.1 didn't change any settings, so they were replaced by working system profiles. **Real Fortnite and Minecraft profiles are planned for v1.3.**
- The Startup apps "Impact" column was a guess, so it was removed.
- "A/B Benchmarking" is now **Snapshots**: it records real CPU/GPU load, clocks and temperatures over time. It doesn't measure FPS.

### Notes
- Windows 10 (1709 or newer) or Windows 11. Run as administrator for tweaks.
- The .exe isn't code-signed, so Windows SmartScreen or antivirus may show a warning.
