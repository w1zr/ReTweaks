## RYTWEAKS v1.4.1

### Sharper app icon
- The `.exe` file icon in File Explorer and on shortcuts is redrawn for small sizes (16–48 px), so the chip outline no longer gets cut off and the R stays crisp.
- The icon on the taskbar and the window while RYTWEAKS is running stays exactly the same as in v1.4.
- The dark rounded square stays, so the icon is visible on both light and dark backgrounds.

Everything from v1.4 is unchanged. If you're on v1.4, use the **Update now** bar at the top of RYTWEAKS. Your settings are kept.
