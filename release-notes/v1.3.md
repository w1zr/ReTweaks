## RYTWEAKS v1.3

### In-app updates
- RYTWEAKS checks GitHub for new versions when it starts. When one is out, an **Update available** button appears in the sidebar.
- **Download and install** gets the new version, checks its SHA-256 fingerprint, keeps your current version as `RYTWEAKS.old.exe`, and restarts. It always asks first, and your settings are kept.
- **Report a problem** copies a hardware report (no personal info) and opens a GitHub issue.

### Game presets
- **Fortnite, Minecraft Java, Minecraft Bedrock, Apex Legends and Rocket League.**
- Presets: **Low**, **High**, **Ultra** and **Ultra Performance**.
- **Custom:** see and edit every setting in the game's settings file, and save your own presets.
- **Choose your own file:** works with any game's settings file (key=value, key:value or "key" "value" formats), including CS2.
- Safe by design:
  - It shows exactly what will change first.
  - It backs up the file before every change, and any backup can be restored.
  - It only changes settings that already exist in your file.
  - It won't touch the file while the game is running.
  - It never touches game programs or anti-cheat files.
- Your **original** settings file (from before RYTWEAKS first changed it) is always kept, plus the 10 most recent backups.
- An optional file lock is available for games that overwrite their settings, like Apex and Rocket League.

### Program rules and auto game mode
- Pick any game or program (.exe) and choose:
  - **Which graphics card** it uses (the same setting as Windows Settings → Graphics).
  - **Fullscreen optimizations** off (the same as the Compatibility tab).
  - **CPU priority** while it runs.
- **Auto game mode:** when the game starts, RYTWEAKS switches to the Ultimate Performance power plan. When it closes, your previous plan comes back.

### More tweaks, with undo
- New tweaks: mouse acceleration, transparency effects, Shift-key accessibility pop-ups, optimizations for windowed games, Fast Startup and hibernation.
- Tweaks are split into **Standard** and **Advanced**. Each shows its trade-off and whether it needs admin rights or a restart.
- Every tweak saves your original setting first and has its own **Undo**.
- **Undo everything RYTWEAKS changed** restores it all in one click, including the power plan and DNS.
- **Create restore point** makes a Windows System Restore point. It tells you honestly if Windows didn't create one (Windows allows one per 24 hours).

### Network tests
- **DNS speed test:** measures real lookup times for Cloudflare, Google, Quad9, your current DNS and custom servers. It reports popular sites and uncached lookups separately, and states the method. It never changes your DNS on its own.
- **Ping test** to 1.1.1.1 or 1.0.0.1: average, best, worst, jitter and packet loss.

### Settings
- Custom accent color (HEX), °C or °F, choose which page opens first.
- **Start with Windows**, optionally minimized, without a UAC pop-up at sign-in.
- Checkboxes are easier to see.

### Fixes and safety
- Only one copy of RYTWEAKS runs at a time.
- If RYTWEAKS was started with a different administrator account than the one signed in, it warns you that "your" settings would change that other account.

### Notes
- Program rules' CPU priority and auto game mode work while RYTWEAKS is open. Turn on Start with Windows (minimized) to keep it running in the background.
- Some anti-cheat-protected games don't allow changing their CPU priority. RYTWEAKS says so when that happens.
- The .exe isn't code-signed, so Windows SmartScreen may show a warning.
