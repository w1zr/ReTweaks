# ReTweaks 2.0.7

**Download:** `RETWEAKS.exe` (or `RETWEAKS.zip`) below. Already have ReTweaks? Click **Update now** in the app. Your settings are kept.

## What's new

- **Fortnite-only stretched resolution now sticks.** Fortnite rewrote its settings file when it started, so the resolution went back to normal. Now:
  - After saving, ReTweaks makes the file read-only so Fortnite can't reset it. A new checkbox controls this, and it's on by default. **Restore previous resolution** unlocks the file again.
  - Fortnite's other size settings (DesiredScreenWidth/Height) are changed too, when the file has them.
  - **Finds Fortnite's settings file automatically** when the page opens and shows where it is. It looks in your account and every other Windows user profile, because ReTweaks runs as administrator and that can be a different account. **Choose Fortnite settings file** still works if you want a different one.
  - Before saving, ReTweaks checks whether your graphics card offers that size on your monitor. Fullscreen can't use a size the card doesn't offer. If yours doesn't, it tells you to add it as a custom resolution in your graphics driver, and to set scaling to Full-screen. It only reads the list; your screen isn't changed.
- **No more `RETWEAKS.old.exe`.** Updating replaces ReTweaks without leaving a copy of the previous version behind. If the update can't be put in place, the current version is restored, as before.
- A `RETWEAKS.old.exe` left by an earlier update is deleted automatically the next time ReTweaks starts. Only that exact file is removed. The deletion is listed in the activity log.
- **Dashboard summary no longer shows the CPU twice.** Some prebuilt PCs report the CPU name as the PC model; that model is now left out, and repeated items show once.

Full feature list: see the [2.0.5 release](https://github.com/w1zr/ReTweaks/releases/tag/v2.0.5).
