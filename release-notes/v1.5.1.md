# RETWEAKS v1.5.1

Fixes for v1.5. If you have v1.5, use the **Update now** bar at the top of RETWEAKS. Your settings are kept.

### Fixed
- **Invisible window after reopening.** Opening RETWEAKS while it was in the tray played the startup animation, then the window stayed see-through (you could see it in the taskbar but not click it). The window now always fades in fully.
- **Quit RETWEAKS didn't fully close it.** Quitting from the tray removed the icon, but RETWEAKS kept running invisibly in the background, which caused "RETWEAKS is already running" when you opened it again. It now really closes.

### Improved
- **Opening a newer version while an older one is running** (for example right after downloading an update) asks whether to close the old one and open the new one. It closes normally, so things like auto game mode put your power plan back first.
- If a RETWEAKS from before v1.5.1 is still running in the background, opening v1.5.1 offers **Close it and start**.

Everything else from v1.5 is unchanged.
