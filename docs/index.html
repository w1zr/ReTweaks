What's inside

Built for a gaming PC, honest on any PC

Hardware detection works for every brand. Anything Windows can't report shows "Unavailable" instead of a made-up value.

Hardware & live data

Exact GPU name from the driver, 64-bit VRAM via DirectX, live GPU load from the same counters Task Manager uses, real CPU clock, disk health, monitors, audio. Temps and fans read from LibreHardwareMonitor when you run it.

Tweaks

53 tweaks across Gaming, Privacy, Interface, Services and Maintenance. Every one explains what it does and the trade-off, shows its current state, saves the original value first, and offers Undo and Undo everything.

FPS test & overlay

Real FPS and 1% / 0.1% lows with Intel PresentMon. A click-through in-game FPS overlay with a built-in ETW frame source. Nothing is ever injected into a game process.

Game presets

Low, High, Ultra and Ultra Performance presets for Fortnite, Minecraft Java, Minecraft Bedrock, Apex Legends and Rocket League. Config files are backed up first, only existing keys change, and nothing runs while the game is open.

Profiles & program rules

Esports, Max FPS, Balanced, Low-end PC, Streamer, Privacy and more. Preview shows only the changes that would actually happen. Per-program GPU preference, CPU priority and auto game mode.

Network & DNS

Choose your own DNS per adapter, with presets, custom IPv4/IPv6, and an Automatic option. DNS speed test with real lookup times. Ping tests against 1.1.1.1 / 1.0.0.1.

Audio mixer

Master volume, per-app volume and mute, output and input device switching, and a volume lock. Uses Windows Core Audio and stays in sync with changes made outside RETWEAKS.

Startup, storage, cleanup

Startup apps from Run keys, Startup folders and Scheduled Tasks, with restore. Storage Explorer, disk space analyzer and temp cleanup that always previews before deleting.

And more

Health Check, display refresh rate and stretched resolution, sensor logging to CSV, auto clicker with emergency stop, a built-in browser (Edge WebView2), Gemini AI Assistant with your own key, themes and a theme maker, Discord status, in-app updates.

What the app does at each step

  • Reads the real current value and shows it before you touch anything.
  • Nothing changes until you press Apply. Never on launch, never silently.
  • Saves the original value first, then writes the documented Windows value.
  • Reports the result only after Windows confirms it.
  • Undo restores the exact original. Undo everything rolls back the whole session.

How it works

The rules every feature follows

Nothing fake

  • Every control performs a real Windows action and reports the true result.
  • No placeholder data, no fake math, no hardcoded device hacks.
  • Loading indicators appear only for real work. No artificial waits.
  • No FPS or ping gain is claimed unless it was measured on your PC.

Nothing you can't undo

  • Tweaks are never applied silently and never on launch.
  • Previous state is recorded before the first change. Undo restores it exactly.
  • Game config files, your power plan and your DNS are backed up before changes.
  • Cleanup always shows a preview. Nothing is deleted without you.

Documented mechanisms only

  • Game Mode, HAGS, Ultimate Performance and service start types use the values Windows itself writes.
  • No invented registry keys and no "FPS boost" folklore presented as fact.
  • No anti-cheat bypass, no stealth features, no game process injection.

Your data stays yours

  • Settings persist between versions. Old settings are never reset.
  • The Gemini key lives only in Windows Credential Manager. No key is in the code or the repo.
  • The AI Assistant gives advice only and never runs commands or changes settings.

Get it

Download

  1. Open the latest release on GitHub. Each release has RETWEAKS.exe, RETWEAKS.zip (the same file zipped) and RETWEAKS.exe.sha256.
  2. Download RETWEAKS.exe and run it. There is no installer. It asks for administrator rights because several tweaks change system-wide settings.
  3. Optional: check the download against the .sha256 file. The in-app updater does this automatically for later versions.

Windows SmartScreen may warn you. The .exe is not code-signed, so Windows or your antivirus can show a warning on first run. All source files are viewable on GitHub, and every release is built from the committed code by GitHub Actions on a Windows runner.

Requirements. Windows 10 or 11, 64-bit. Optional: LibreHardwareMonitor for CPU temperatures and fan speeds, Intel PresentMon for the FPS test, and your own Gemini API key for the AI Assistant (18+ per Google's terms).

Questions

FAQ

Is it free?

Yes. RETWEAKS is free and its source is public on GitHub. A paid Pro tier was considered and is on hold.

Why does it need administrator rights?

Tweaks like the power plan, DNS, HAGS and service start types change system-wide Windows settings, which require admin. The app tells you which tweaks are system-wide, and a declined UAC prompt is handled without crashing.

Why can't it show my CPU temperature?

Windows has no API for CPU temperatures, fans or motherboard sensors without a kernel driver, and RETWEAKS does not ship one. Run LibreHardwareMonitor and RETWEAKS reads those values from it. Otherwise it shows "Unavailable" rather than a guess.

Will it make my FPS higher?

It won't promise that. Tweaks are reversible changes to documented Windows settings. Use the FPS test and Snapshots to compare before and after on your own PC, and keep only what measurably helps.

Does the overlay work with anti-cheat?

The overlay is a separate click-through window and never injects into a game process. It draws over borderless and windowed-fullscreen games; exclusive fullscreen draws over it.

Something broke. Where do I report it?

Use the Report a problem button: it copies the specs your browser can see, then opens a bug form on GitHub where you paste them. Add the RETWEAKS version from the About page and what you did right before the problem.

What was RYTWEAKS?

The previous name. Version 1.6 renamed the project to RETWEAKS. Settings, themes and the Gemini credential migrate automatically, and old theme share codes still import.
