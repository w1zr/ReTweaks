        What the app really does

        • Nothing runs until you press Run ticked. Never on launch, never silently.
        • A Windows restore point is requested first. Windows allows one per 24 hours by default; if it refuses, the log says so.
        • Each tweak's commands are logged as [ok] or [!!] with Windows' own output.
        • Undo ticked puts these tweaks back to Windows defaults. One-shot items, like cleaning temp files, have nothing to undo.
        • Want your exact previous values back instead? The 53 tweaks on the Exact undo tab read your current value first and restore it exactly.

        Nothing fake

        • Every control performs a real Windows action and reports the true result.
        • No placeholder data, no fake math, no hardcoded device hacks.
        • Loading indicators appear only for real work. No artificial waits.
        • No FPS or ping gain is claimed unless it was measured on your PC.

        Nothing you can't undo

        • Tweaks are never applied silently and never on launch.
        • Previous state is recorded before the first change. Undo restores it exactly.
        • Game config files, your power plan and your DNS are backed up before changes.
        • Cleanup always shows a preview. Nothing is deleted without you.

        Documented mechanisms only

        • Game Mode, HAGS, Ultimate Performance and service start types use the values Windows itself writes.
        • No invented registry keys and no "FPS boost" folklore presented as fact.
        • No anti-cheat bypass, no stealth features, no game process injection.

        • Fans and lighting are never changed at startup unless you turn that on. Fans return to BIOS control on quit, crash or 85 °C.

          Questions
          FAQ
          
  
          
  
          Is it free and open source?
          Yes. RETWEAKS is free and all source code is on GitHub under the GPL-3.0 license.
          
  
          Why does it need administrator rights?
          Tweaks like the power plan, DNS, HAGS and service start types change system-wide Windows settings, which require admin. The app tells you which tweaks are system-wide, and a declined UAC prompt is handled without crashing.
          
  
          Why can't it show my CPU temperature or control my fans?
          Windows has no API for CPU temperatures, motherboard sensors or fan control without a kernel driver, and RETWEAKS never installs drivers itself. Install the free PawnIO driver from its official page (there's a button on the Temperatures page) and those readings appear. Some motherboards don't allow fan control at all; RETWEAKS says so instead of pretending. Until then it shows "Unavailable".
          
  
          Will it make my FPS higher?
          It won't promise that. Tweaks are reversible changes to documented Windows settings. Use the FPS test and Snapshots to compare before and after on your own PC, and keep only what measurably helps.
          
  
          Do the FPS and crosshair overlays work with anti-cheat?
          Both are separate click-through windows and never inject into a game process. They draw over borderless and windowed-fullscreen games; exclusive fullscreen draws over them. Follow each game's rules on overlays and crosshairs.
          
  
          Which languages does it have?
          English, Español, Français, Deutsch and Português (Brasil), switchable in Settings without a restart. The translations are machine-made; corrections are welcome on GitHub or Discord.
          
  
          How do I update?
          An Update now bar appears at the top of every page when a new version is out. It downloads the new .exe, checks its SHA-256, and keeps the old one as RETWEAKS.old.exe. You can also turn on automatic updates, which download in the background and ask before restarting. Your settings are kept.
          
  
          Is there a community?
          Yes, the RETWEAKS Discord: discord.gg/fS5NwW9TPF. Questions, feedback and theme codes go there.
          
  
          Something broke. Where do I report it?
          Use the Report a problem form: pick the kind of problem, say what happened, and it opens a filled-in report on GitHub or copies a message for the Discord. Attach crash.log from %APPDATA%\RETWEAKS if the app crashed.
          
  
          I had an older version. Do my settings carry over?
          Yes. Settings, theme, tweak backups, game backups, program rules and browser bookmarks stay where they were, undo still works for tweaks applied with earlier versions, and old theme share codes still import.
